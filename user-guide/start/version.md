# Choose your version

Check the version shown by your TR4W build before choosing instructions.

| What you are running | Start here |
| --- | --- |
| Public Windows 4.x release | Use the [TR4W website](https://tr4w.net/) for downloads and the [wiki](https://github.com/TR4W/TR4W/wiki) for its manual. |
| FreePascal/Lazarus 5.x preview | Use this guide as a draft companion to your build's release notes. |
| Native Linux 5.x preview | Read [Linux requirements and troubleshooting](install.md#linux-requirements-and-troubleshooting) in this guide. |
| Native macOS 5.x | TR4W runs natively on macOS. See the [installation guide](install.md) for `.pkg`, `.dmg`, and archive installation choices. |

## Native desktop builds

This version runs natively on Windows, macOS, and Linux. Use the package built for your platform and CPU. Platform-specific hardware and packaging notes still apply.

The Linux packages covered here are preview builds. The tarball and AppImage have different glibc requirements. See [installation requirements](install.md#linux-requirements-and-troubleshooting) and [CW sending options](../station/cw.md) for platform limitations. Package requirements depend on how the artifact was built.
