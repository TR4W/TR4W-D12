# Earlier manuals and wiki

The [TR4W wiki](https://github.com/TR4W/TR4W/wiki) says it replaces the reference manual v4.01 and covers features through v4.147.07. It is valuable background for 5.x, but storage, dialogs, and platform support require another review.

| Task | Wiki source | What to recheck for 5.x |
| --- | --- | --- |
| Find a command | [Configuration statements](https://github.com/TR4W/TR4W/wiki/Configuration-Statements) | Setting names, defaults, persistence, and scope. |
| Learn operating keys | [Windows and hot keys](https://github.com/TR4W/TR4W/wiki/Program-Windows-and-Hot-Keys) | Current bindings, keyboard layout, OS behavior. |
| Operate from parks | [POTA operation](https://github.com/TR4W/TR4W/wiki/POTA-Operation) | Dialog labels, multi-park entry, and exported ADIF. |
| Set up digital logging | [WSJT-X integration](https://github.com/TR4W/TR4W/wiki/WSJT-X-Integration) | Settings storage and current Reporting controls. |
| Connect other software | [UDP broadcasts](https://github.com/TR4W/TR4W/wiki/UDP-Broadcasts) | Message enablement, ports, and destination settings. |
| Use two radios | [SO2R tips](https://github.com/TR4W/TR4W/wiki/SO2R-Tips) | Hardware support and platform-specific keying. |

The [TR4W website](https://tr4w.net/) links the older PDF user and reference manuals and labels them obsolete. They remain historical background, not the authority for a current 5.x procedure.

The local repository also contains `docs/TR4W_Reference_Manual_4.01-1.md` and `docs/MANUAL_UPDATE_SUMMARY.md`. The latter explains the earlier wiki update and is useful for planning the remaining migration.
