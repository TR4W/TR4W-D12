# About TR4W

**TR4W — Cross-platform contest logging, rooted in TRLOG.**

TR4W is the product name. It carries the history and recognition of a contest logger descended from N6TR's TRLOG as development expands across desktop platforms.

## A familiar name with a longer history

TR4W began as TRLOG for Windows, derived from the DOS-era contest logger created by Larry “Tree” Tyree, N6TR. That history explains the name; it does not limit the application's future to Windows.

TR4W and TRLinux are separate projects. TRLinux is an independent Linux port of the original TRLOG; a native Linux build of TR4W belongs to the TR4W development line.

## One product across platforms

Use **TR4W for Windows**, **TR4W for macOS**, and **TR4W for Linux** when identifying platform-specific builds. The product name stays TR4W.

TR4W runs natively on Windows, macOS, and Linux. This guide documents a development preview; individual hardware features and release readiness still need platform-specific validation. [Choose your version](../start/version.md) identifies the documented snapshot.

## Native applications

The FreePascal/Lazarus application uses native builds for each desktop platform. Install the package for your operating system and follow its hardware and file-location notes.

## For documentation contributors

Lead with **TR4W**, its operating purpose, and its TRLOG heritage. Reserve “TRLOG for Windows” for history. State native platform support clearly and describe any feature-specific limitations where they matter.

This page follows the project's positioning direction supplied for this documentation experiment. Historical project context is available in the [TR4W repository](https://github.com/n4af/TR4W).
