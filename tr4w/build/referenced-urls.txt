# Every URL the tree references (issue 248).  Format and rules: build\ReferencedUrls.psm1.
#
#   url | kind | probe | owner | arg | allow
#
# TWO scripts read this file and nothing else:
#   Lint-ReferencedUrls.ps1     offline, gates the build. Every URL literal under src, tools,
#                               build, tr4wserver and tr4w.lpr must be a row here, and every row
#                               must still be in the tree (a stale row fails).
#   Check-ReferencedUrls.ps1    network, read-only, a PRE-RELEASE step. Probes endpoint, link and
#                               tooling rows (doc rows too with -IncludeDocs).
#
# ADDING AN ENDPOINT: add its row here in the same commit, kind `endpoint`. A URL the program
# POSTS to is probe `root` (the host is asked; nothing is ever sent to the real path).
#
# supercheckhistory.com is probe `skip`, always: call-history files are downloaded before a
# contest and never by a check (docs: supercheckhistory download rules). The lint enforces it.
#
