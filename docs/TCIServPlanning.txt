This project implements a websocket server to implement a TCI protocol receiver. It is communicating with external
clients making TCI calls to AetherSDR (See names of TCI related AetherSDR files below). For example, the Flex radios not Icom radio does not implement the TCI
protocol so Aether acts as a server to offer a TCI server to TCI clients to talk to radios connected to aether that
do not support TCI.
In docs, there are files that discuss the TCI protocol. Additionally TR4W in c:\tr4w-d12 alreadsy implements a TCI
client. What I want to do is implement a similar tCI server so TCI clients can connect to TR4W and utilize those
radios that TR4W is controlling.

The reasoning is that currenlty, we open a socket in the uWSJTX unit to allow external programs to connect to TR4W via a tcp server. This is because in the case of a radio with a serial port, only one program canhave that serial port open. Since both TR4W and WSJTX need data from the radio, we alow WSJTX to use its DXCommander client interface to connect to TR4W.  My thought is to implement a TCI server such that we act as thebridge between a TCP client and the radio.
