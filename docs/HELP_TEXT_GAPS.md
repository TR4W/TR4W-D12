# English help text: what is missing

Generated by `python tools/i18n/ini2po.py --todo --write-doc`. Regenerate rather than hand-editing.

`tr4w/target/commands_help_eng.ini` is the source for every translated help catalogue, so a gap here is a gap in **all** languages. `uOption.pas:842` reads it with `GetPrivateProfileStringA` and a NULL default, so a missing section shows the user a **blank help pane** -- no error, no fallback.

Counts are against the **live** command set only. A `CFGCA` row that is commented out, or marked `crS: csRem`, is deprecated: `CheckCommand` exits early without applying it and the Options dialog hides it, so the user can never reach its help. Those rows are not gaps and are excluded here.

## A. Section missing, but another language has text (4)

These can be written from the existing translation rather than invented. The Spanish or German text is given where available.

### `FREQUENCY MEMORY`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Valores: frecuencia (kHz). Cuando TR4W cambia por primera vez a una banda/modo, tiene una frecuencia a la que irá por defecto. Use este comando si desea cambiar el valor por defecto. Use este comando una vez por cada banda que desee cambiar. Si está especificando una frecuencia que podría procesarse como frecuencia de CW pero que desea que se use como frecuencia de SSB, anteponga SSB (p. ej.: FREQUENCY MEMORY = SSB 7050). Tenga en cuenta que estos valores por defecto se actualizarán con las frecuencias reales utilizadas en los cambios posteriores de banda/modo si establece FREQUENCY MEMORY ENABLE a TRUE.

### `MULTI MULTS ONLY`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Si está utilizando una red de ordenadores para una operación multi, este comando determinará si todos los QSOs se distribuyen por la red, o solo aquellos que son nuevos multiplicadores.

### `RADIO TCP SERVER PORT`

Has text in: ESP, GER, RUS, UKR

> **ESP:** Este es el puerto en el que TR4W escucha entradas para interactuar con la radio que está controlando. Implementa el protocolo DXLab Commander de modo que OTROS programas pueden controlar la radio que TR4W está utilizando. Tenga en cuenta que esto NO es una conexión para permitir que TR4W controle una radio mediante DXLab Commander. Es una conexión entrante pensada principalmente para que WSJT-X controle la radio actual de TR4W.

### `TUNE WITH DITS`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Si este parámetro es TRUE, TR4W envía una cadena de dits a 75 WPM al pulsar ctrl-Left-Shift.
