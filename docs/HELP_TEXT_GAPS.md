# English help text: what is missing

Generated by `python tools/i18n/ini2po.py --todo --write-doc`. Regenerate rather than hand-editing.

**Measured against `tr4w/target/commands_help_eng.ini`**, the authoring source for every help catalogue -- so a gap here is a gap in **all** languages. The program does not read the ini: Preferences shows each bound control's help as its tooltip from `help/help_<code>.po` over `help/help_en.po` (`src/uCommandHelp.pas`), which `ini2po.py` builds from it. A command with no help shows **no tooltip** -- no error. Section E lists where `i18n/help_en.po` lags the ini.

Counts are against the **live** command set: every command the settings object answers to, by its primary name, as `tools/settings_inventory.py` derives it from `uSettingsModel.pas` (the parse behind `tr4w/docs/SETTINGS_INVENTORY.md`). Help is looked up by the name a control is registered under, with no alias resolution; that is always the primary name, so a second name's section in D is not shown. `uTestCommandHelp.KNOWN_HELP_GAPS` pins the subset Preferences registers.

## A. Section missing, but another language has text (3)

These can be written from the existing translation rather than invented. The Spanish or German text is given where available.

### `CALL WINDOW SHOW ALL SPOTS`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Cuando es TRUE, al sintonizar en modo S&P, todos los indicativos que TR4W conozca aparecerán en la ventana de llamada aunque no aparezcan en el bandmap. Por ejemplo, si tiene BAND MAP DUPE DISPLAY establecido a FALSE, los duplicados no aparecerán en el bandmap, pero seguirán apareciendo en la ventana de llamada si CALL WINDOW SHOW ALL SPOTS es TRUE.

### `COUNTRY INFORMATION FILE`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Este comando le permite especificar un fichero que tenga hasta cinco líneas de texto asociadas a un país (los países se definen en el fichero CTY.DAT). El texto se mostrará en la ventana del log editable cuando trabaje la estación. El formato del fichero consiste en el carácter identificador del país (como se usa en el fichero CTY.DAT) en la primera línea, seguido de hasta cinco líneas de texto. Una línea en blanco indica el final de los datos y puede ir seguida del siguiente identificador de país. No hay límite en el tamaño del fichero ni en el número de países.

### `TUNE WITH DITS`

Has text in: CZE, ESP, GER, ROM, RUS, UKR

> **ESP:** Si este parámetro es TRUE, TR4W envía una cadena de dits a 75 WPM al pulsar ctrl-Left-Shift.

## E. `i18n/help_en.po` lags the ini (4)

What the program loads, against what this document measures. Closing these is a run of `python tools/i18n/ini2po.py`, which **merges** the English into every `i18n/help_*.po` -- the `.po` is the master, nothing is lost and no fuzzy flag is cleared (see `_merge`) -- and then the `mt_seed --only` lines it prints. Not run by this report.
